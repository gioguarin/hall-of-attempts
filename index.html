About & how it was made
THE PROCESS

How I made these models

I made this collection on an Apple Silicon Mac, using AssetFurnace to run Pixal3D locally. Each model started with a single still image.

Local generationOne image per objectAbout 5,000 triangles per model

  1. Start with an image

    Four exhibits began as photographs. For the bumper car, oil drum and road barrier, I generated reference images locally with FLUX.2 [klein] 4B.

  2. Separate the subject

    I removed the backgrounds to give the reconstruction a clearer silhouette and keep the surrounding scene out of the mesh.

  3. Generate the model

    Pixal3D turned the image into geometry and textures. The unseen sides were inferred from a single view, so this is where much of the invention—and the failure—happens.

  4. Prepare it for the web

    AssetFurnace’s Finish stage reduced the meshes to roughly 5,000 triangles, baked their textures and compressed the exports. The gallery uses meshopt-compressed GLBs, with 512-pixel overview textures and 1024-pixel textures for close-ups.

  5. Inspect the attempts

    I compared each result with its source image, recorded what survived, and adjusted the models’ orientation and placement for this three.js gallery. The reconstruction artifacts remain part of the exhibit.

One image cannot reveal every surface. Thin structures, hollow interiors and lettering often break down. The verdicts beside each piece describe what worked and what was lost.
