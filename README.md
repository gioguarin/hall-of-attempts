# The Hall of Attempts

Local image-to-3D attempts on Roman columns. Static three.js page, no build step.

    python3 -m http.server 8080

Live: https://gioguarin.github.io/hall-of-attempts/ (once Pages is enabled)

## Pieces

9 exhibits, all generated locally with Pixal3D from a single image each, retopologised to
~5,000 faces, textures at 1024², meshopt-compressed. Total models: 6.4 MB.

Browsing: arrows / wheel / numbered strip / click a piece. Esc returns to the overview.
Drag in focus rotates the piece. `#/4` deep-links an exhibit.
